# E. 作者原文逻辑框架

## 1. 原作者的因果链条（Authors' Causal Chain）
*   **环境暴露**：夜间个人光照暴露（手腕光传感器数据，91–100 百分位 vs. 0–50 百分位）
*   **生理中转信号**：
    1.  昼夜节律紊乱（光照抑制褪黑素、相位偏移）
    2.  自主神经失衡：交感激活（心率↑，心率变异性↓）
    3.  代谢紊乱：胰岛素抵抗↑、肥胖、高血压、糖尿病风险↑
*   **最终疾病表型**：
    *   冠状动脉疾病（HR 1.32）
    *   心肌梗死（HR 1.47）
    *   心力衰竭（HR 1.56）
    *   心房颤动（HR 1.32）
    *   卒中（HR 1.28）

**总结链条**：
夜间光照 → 昼夜节律紊乱 + 自主神经失衡 + 代谢紊乱 → 心血管疾病风险全面增加

## 2. 对异质性/悖论的解释（Explanation of Anomalies）
*   **性别差异**：女性在夜间光照下心力衰竭风险更高（交互作用 P=0.006），可能与女性对光照的昼夜节律敏感性更高有关。
*   **年龄差异**：年轻人心力衰竭和心房颤动风险对光照更敏感（交互作用 P=0.04），可能与老年人节律系统敏感性下降有关。
*   **日间光照与风险降低**：日间光照与部分心血管疾病风险降低相关，但在调整体力活动后关联减弱，提示日间光照可能通过促进活动量间接保护心血管。

## 3. 作者的“假说”与“猜测”（Speculative Hypotheses）
*   **潜在机制**：光照通过抑制褪黑素、影响G蛋白偶联受体MTNR1B等通路，干扰胰岛素分泌和血糖节律。
*   **未来研究**：
    1.  长期光照干预试验
    2.  不同光源（如蓝光、红光）的影响
    3.  光照与基因-环境交互作用
    4.  在非白人人群、不同社会经济群体中的推广性

## 4. 转化建议的颗粒度（Granularity of Translation）
*   **具体建议**：
    1.  避免夜间光照：尤其是睡前和睡眠期间
    2.  使用遮光窗帘、眼罩
    3.  避免在卧室内使用电子设备
    4.  日间增加户外光照，以强化昼夜节律
    5.  在护理机构、医院等场所设计节律友好型照明系统

## 5. 局限性自我评价（Study Limitations）
1.  **人群代表性**：UK Biobank参与者主要为白人（97%）、教育程度高、女性比例高（57%），可能限制推广性
2.  **光照测量时间短**：仅一周光传感器数据，未能反映长期光照模式
3.  **光源信息缺失**：无法区分自然光与人造光、光源类型（如屏幕光）
4.  **潜在残留混杂**：体力活动等可能既是中介也是混杂
5.  **观察性研究**：无法确立因果关系
