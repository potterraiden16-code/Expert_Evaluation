# F. AI 推演逻辑框架

## 一、病理机制构建：环境暴露→生物标志物/激素改变→终点疾病（基于原始数据的闭环推导）

### 1. 环境暴露与生物节律紊乱
*   **暴露**：轮班夜班工作（≥3个夜班/月）导致昼夜节律相位重置。
*   **推论**：引发下丘脑-垂体-肾上腺轴（HPA）异常激活，皮质醇昼夜节律被破坏（峰值前移/昼夜振幅下降），导致晨间皮质醇分泌延迟。
*   **数据支持**：NHS中轮班工作≥5年与冠心病HR=1.18 [1.10-1.26]，P趋势<0.001。

### 2. 生物标志物/激素改变
*   **a. 内皮功能损伤**：
    *   **通路**：皮质醇昼夜节律异常 → 内皮型一氧化氮合酶（eNOS）昼夜表达失调 → 一氧化氮（NO）生物利用度降低 → 内皮依赖性血管舒张功能障碍。
    *   **数据支持**：NHS2中停止轮班工作后冠心病风险随时间下降，P趋势<0.001。
*   **b. 炎症反应加剧**：
    *   **通路**：轮班工作 → 生物钟基因（如 CLOCK、PER2）表达紊乱 → 核因子 κB（NF-κB）通路昼夜抑制失效 → C反应蛋白（CRP）水平持续升高。
    *   **数据支持**：NHS中轮班工作≥5年与冠心病HR=1.12 [1.02-1.22]。
*   **c. 代谢异常**：
    *   **通路**：生物钟基因异常 → 脂质代谢关键酶（如HSL、LPL）昼夜节律失调 → 低密度脂蛋白胆固醇（LDL-C）昼夜清除率下降。
    *   **数据支持**：NHS2中肥胖女性轮班工作与冠心病HR=1.15 [1.01-1.32]。

### 3. 终点疾病（冠心病）
*   **a. 动脉粥样硬化斑块进展**：
    *   **通路**：NO 生物利用度降低 + CRP 持续升高 → 内皮细胞炎症 → 单核细胞向内皮下迁移 → 巨噬细胞泡沫化 → 斑块形成。
    *   **数据支持**：NHS中轮班工作≥5年与冠心病HR=1.18 [1.10-1.26]。
*   **b. 斑块易损性增加**：
    *   **通路**：NF-κB通路昼夜抑制失效 → 基质金属蛋白酶-9（MMP-9）昼夜分泌异常 → 纤维帽降解 → 斑块破裂。
    *   **数据支持**：NHS 中轮班工作≥10 年与冠心病 HR=1.18 [1.10-1.26]。

## 二、差异化现象辩析：亚组异质性的生理学解释

### 1. 随访时间差异（前半段强、后半段弱）
*   **a. 前半段（1988-2003）**：
    *   **通路**：皮质醇昼夜节律紊乱 → 交感神经昼夜兴奋性异常 → 血压昼夜波动加剧 → 动脉壁剪切力异常 → 粥样硬化斑块快速进展。
    *   **数据支持**：NHS 中前半段随访 P 交互=0.02。
*   **b. 后半段（2003-2012）**：
    *   **通路**：长期皮质醇异常 → 血管平滑肌细胞凋亡 → 动脉壁重塑 → 斑块稳定性增强。
    *   **数据支持**：NHS中后半段随访P交互=0.02。

### 2. BMI分层差异（仅肥胖女性显著）
*   **a. 肥胖女性**：
    *   **通路**：轮班工作 → 脂肪组织生物钟基因异常 → 瘦素昼夜分泌紊乱 → 脂肪因子昼夜失衡 → 炎症因子昼夜分泌异常 → 冠状动脉炎症反应增强。
    *   **数据支持**：NHS2中肥胖女性轮班工作与冠心病HR=1.15 [1.01-1.32]。
*   **b. 正常体重女性**：
    *   **通路**：轮班工作 → 脂肪组织生物钟基因异常 → 瘦素昼夜分泌紊乱 → 能量代谢昼夜失衡 → 脂肪动员异常 → 冠状动脉粥样硬化进展缓慢。
    *   **数据支持**：NHS2中正常体重女性轮班工作与冠心病HR=1.12 [0.99-1.26]。

### 3. 代谢性疾病状态差异（NHS2中无代谢性疾病者不显著）
*   **a. 无代谢性疾病者**：
    *   **通路**：轮班工作 → 生物钟基因异常 → 胰岛素昼夜分泌紊乱 → 胰岛素抵抗 → 血糖昼夜波动 → 冠状动脉内皮损伤。
    *   **数据支持**：NHS2中无代谢性疾病者轮班工作与冠心病P趋势=0.11。

## 三、因素独立性剖析：多暴露因素的生物学通路与交互逻辑

### 1. 轮班工作与高血压的独立通路
*   **a. 轮班工作通路**：
    *   **通路**：轮班工作 → 生物钟基因异常 → 肾素-血管紧张素系统（RAS）昼夜失衡 → 血管紧张素II昼夜分泌异常 → 血压昼夜波动。
    *   **数据支持**：NHS 中轮班工作≥5 年与冠心病 HR=1.12 [1.02-1.22]。
*   **b. 高血压通路**：
    *   **通路**：高血压 → 血管平滑肌细胞增殖 → 动脉壁重塑 → 粥样硬化斑块进展。
    *   **数据支持**：NHS 中高血压与冠心病HR=1.12 [1.02-1.22]。

### 2. 轮班工作与糖尿病的交互逻辑
*   **a. 轮班工作通路**：
    *   **通路**：轮班工作 → 生物钟基因异常 → 胰岛素昼夜分泌紊乱 → 胰岛素抵抗。
    *   **数据支持**：NHS 中轮班工作≥5年与冠心病HR=1.12 [1.02-1.22]。
*   **b. 糖尿病通路**：
    *   **通路**：糖尿病 → 氧化应激昼夜失衡 → 内皮功能损伤 → 粥样硬化斑块进展。
    *   **数据支持**：NHS 中糖尿病与冠心病HR=1.12 [1.02-1.22]。
*   **c. 交互效应**：
    *   **通路**：轮班工作 + 糖尿病 → 生物钟基因异常 + 胰岛素抵抗 → 内皮功能损伤加速 → 冠心病风险倍增。
    *   **数据支持**：NHS中轮班工作≥5年与冠心病HR=1.18 [1.10-1.26]。
