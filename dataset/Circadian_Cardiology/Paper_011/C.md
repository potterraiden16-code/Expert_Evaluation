# F. AI 推演逻辑框架

## 一、病理机制构建（环境暴露 → 生物标志物/激素改变 → 终点疾病）

### 1. 光照暴露 → 交感神经激活 → 心率/低频/高频比改变 → 早期胰岛素分泌增加
*   **数据支撑**：房间光照组心率增加（条件 × 夜 P<0.0001）；低频/高频比增加（条件 × 夜 P=0.019）；30 分钟胰岛素曲线下面积变化显著大于弱光组（条件 × 天 P=0.030）。
*   **机制推导**：
    光照通过视网膜-下丘脑通路激活交感神经，抑制迷走神经张力（低频/高频比升高）→ 心率增加 → 胰岛β细胞交感神经输入增强 → 胰岛素早期分泌增加。此通路独立于褪黑激素，因褪黑激素水平无显著变化（24小时水平无差异）。

### 2. 交感神经激活 → 胰岛素抵抗/胰岛素敏感性下降
*   **数据支撑**：HOMA-IR在房间光照组增加（P=0.018）；松田指数下降（P=0.048）；30分钟胰岛素曲线下面积增加（P=0.030）。
*   **机制推导**：
    交感神经激活导致脂肪分解增加 → 游离脂肪酸（FFA）释放 → 胰岛素受体磷酸化抑制 → 胰岛素抵抗。同时，β细胞去极化时间缩短 → 胰岛素分泌峰值提前 → 胰岛素敏感性下降。此通路与睡眠结构改变无关（睡眠宏观结构变化与代谢指标无关联）。

### 3. 交感神经激活 → N2期增加/SWS/REM减少 → 睡眠宏观结构改变
*   **数据支撑**：N2期比例增加（P=0.004）；SWS/REM比例减少（P=0.017/0.033）。
*   **机制推导**：
    交感神经激活抑制慢波睡眠（SWS）生成的丘脑-皮层网络（如网状结构去极化），同时促进 N2 期的轻度觉醒 → 睡眠深度降低。此改变与褪黑激素无关（褪黑激素起始/偏移时间无差异）。

## 二、差异化现象辩析（异质性解释）

### 1. 为何仅影响早期胰岛素分泌而非总分泌（2小时曲线下面积无差异）？
*   **数据支撑**：30分钟胰岛素曲线下面积增加（P=0.030）；2小时总曲线下面积无差异。
*   **机制解释**：
    早期分泌（30分钟）由β细胞胞吐颗粒直接释放，受交感神经快速调节；而总分泌涉及β细胞葡萄糖敏感性（葡萄糖激酶活性），受光照影响较小。此差异表明交感神经对β细胞的快速反应性调节独立于代谢功能的长期改变。

### 2. 为何仅在房间光照组内观察到低频/高频比与早期胰岛素分泌的关联？
*   **数据支撑**：房间光照组低频/高频比变化与 30 分钟胰岛素曲线下面积变化显著相关（R=0.74, P=0.013）；弱光组无关联（R=0.56, P=0.10）。
*   **机制解释**：
    弱光条件下自主神经基线波动较小，无法区分交感神经激活的附加效应；而房间光照的高强度刺激放大了交感神经对 β 细胞的快速反应性调节，使两者关联显现。此现象表明交感神经对β细胞的调节需达到特定激活阈值。

## 三、因素独立性剖析（独立通路与交互逻辑）

### 1. 交感神经激活的独立通路
*   **数据支撑**：心率增加（P<0.0001）；低频/高频比增加（P=0.019）。
*   **机制推导**：
    光照通过视网膜-下丘脑通路直接激活交感神经中枢，独立于褪黑激素和睡眠结构改变。此通路解释了为何心率和低频/高频比变化与代谢指标相关，而睡眠宏观结构变化无关联。

### 2. 交感神经与β细胞的交互逻辑
*   **数据支撑**：30 分钟胰岛素曲线下面积增加（P=0.030）；松田指数下降（P=0.048）。
*   **机制推导**：
    交感神经激活通过 α1 肾上腺素能受体快速促进 β 细胞胞吐颗粒释放（早期分泌），但通过β2肾上腺素能受体抑制葡萄糖激酶活性，导致胰岛素敏感性下降。此交互逻辑解释了为何早期分泌增加而总分泌无变化。

## 四、转化价值产出（创新干预方案）

### 1. 光照干预方案
*   **方案设计**：在夜间使用可调节色温的照明系统，将色温从5500K（白光）降至2700K（暖光），同时将光照强度从100 lx降至3 lx。
*   **科学依据**：
    降低色温可减少对视网膜内在光敏神经节细胞（ipRGCs）的激活 → 交感神经抑制 → 胰岛素早期分泌减少 → 改善胰岛素抵抗。此方案可避免褪黑激素抑制（因光照强度未达抑制阈值）。

### 2. 交感神经调节药物
*   **方案设计**：开发选择性α1肾上腺素能受体拮抗剂（如特拉唑嗪）的缓释制剂，用于夜间服用。
*   **科学依据**：
    α1 受体拮抗剂可阻断交感神经对 β 细胞胞吐颗粒的快速释放 → 降低早期胰岛素分泌 → 改善胰岛素敏感性。此方案需避免β2受体激活，以防止脂肪分解增加。

### 3. 睡眠结构优化策略
*   **方案设计**：在夜间使用低频声波刺激（1-4 Hz）以增强慢波睡眠（SWS）。
*   **科学依据**：
    低频声波可通过听觉-丘脑通路促进 SWS 生成，抵消交感神经激活对 SWS 的抑制 → 改善睡眠深度 → 间接降低交感神经张力 → 减少早期胰岛素分泌。

## 五、数据不足说明
*   褪黑激素起始/偏移时间与代谢指标无显著关联，可能因样本量较小（n=20）或光照强度未达抑制阈值，无法推导完整因果链。
