# E. 作者原文逻辑框架

## 1. 因果链条
*   **环境暴露**：
    *   户外夜间光污染（LAN）
    *   空气污染物：PM₂.₅、PM₁₀、NO₂
*   **核心生理/分子中转信号**：
    *   **LAN通路**：LAN → 昼夜节律紊乱 → 褪黑激素分泌抑制 → 代谢紊乱（血脂、血糖、血压升高）
    *   **空气污染通路**：空气污染 → 氧化应激与系统炎症 → 动脉粥样硬化加速（缺血性卒中）或血管功能障碍（出血性卒中）
*   **最终疾病表型**：
    *   脑血管疾病总体风险增加（HR = 1.17 per IQR for LAN；HR = 1.25 for PM₂.₅）
    *   缺血性卒中风险增加，与出血性卒中无显著关联

## 2. 对异质性/悖论的解释
*   **卒中亚型差异**：
    *   **现象**：LAN 与 PM₂.₅ 主要与缺血性卒中相关，与出血性卒中无显著关联。
    *   **解释**：空气污染物可能主要通过促动脉粥样硬化机制影响缺血性卒中，而LAN 可能通过代谢与血压途径影响缺血事件。
*   **收入水平调节作用**：
    *   **现象**：PM₂.₅ 与脑血管疾病的关联在低收入人群中更强。
    *   **解释**：高收入人群可能有更多资源减少污染暴露。

## 3. 作者的“假说”与“猜测”
*   **潜在交互作用**：
    *   理论上，LAN 抑制褪黑激素可能增强 PM₂.₅ 的促动脉粥样硬化作用，但本研究未观察到显著交互。
    *   未来需在大样本中进一步验证光污染与空气污染的联合效应。
*   **光谱影响**：
    *   短波长光（如 LED 蓝光）可能对褪黑激素抑制更强，但本研究未评估光谱组成。
    *   建议未来研究评估不同类型光源的健康影响。

## 4. 转化建议的颗粒度
*   **干预建议**：
    *   限制波长 ≤540 nm 的户外光，减少蓝光暴露。
    *   结合空气污染控制策略，制定综合性的环境健康政策。
*   **筛查建议**：
    *   在高 LAN 与高污染地区加强脑血管疾病风险评估与早期筛查。

## 5. 局限性自我评价
*   暴露评估基于基线住址，未考虑人员流动与时间变化。
*   未获取室内照明与窗帘使用数据，无法反映总光暴露。
*   卫星数据光谱范围有限（500–900 nm），可能低估蓝光影响。
*   未控制夜间交通噪音等潜在混杂。
*   随访时间较短，卒中亚型病例数有限。
*   样本来自宁波一区，外推性有限。
