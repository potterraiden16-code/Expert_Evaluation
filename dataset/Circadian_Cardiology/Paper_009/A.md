# A. 研究背景与已知先验

## 1. 研究背景与已知先验知识
*   日光节律和氧气供应对人类健康至关重要。
*   生物体普遍具备光感受（如PER2）和氧感受（如HIF1A）通路。
*   HIF1A是进化保守的转录因子，帮助细胞适应低氧环境；PER2是光诱导的昼夜节律核心蛋白，两者均属于PAS结构域超家族。
*   在小鼠心脏组织中，Hif1a mRNA水平呈昼夜节律性波动。
*   昼夜节律的光感受与氧感受通路在进化上相互关联，可能在心肌缺血等低氧疾病中发挥作用。

## 2. 本研究实验设计事实
### a) 研究基本面
*   **动物样本量**：
    *   C57BL/6J小鼠，每组 n = 4–6。
    *   Per2−/− 小鼠，每组 n = 5–6。
    *   内皮特异性PER2缺陷小鼠，每组 n = 3–5。
*   **人类样本量**： 17名健康志愿者（11女，6男，年龄21–44岁）。
*   **随访时间**：
    *   小鼠：暴露于强光（10,000 lux）3、5或7天。
    *   人类：连续5天，每天30分钟暴露于强光。

### b) 暴露与终点
*   **暴露（自变量）**： 强光暴露（10,000 lux，L:D 14:10）。
*   **测量方式**： 光强度、光周期、暴露时间。
*   **终点（因变量）**：
    *   心肌梗死大小：计算梗死面积占风险区域百分比。
    *   血清肌钙蛋白-I水平：ELISA检测。
    *   PER2蛋白水平：荧光素酶报告基因检测、免疫印迹。
    *   HIF1A-HRE结合：转录因子结合实验。
    *   糖酵解通量：U-13C-葡萄糖同位素示踪，LC-MS/MS检测。
    *   血管通透性：Evans blue渗漏实验。
    *   内皮屏障功能：TEER（跨内皮电阻）。
    *   睡眠行为：加速度计检测。

### c) 核心关联数据（显著结果）
*   强光暴露7天显著减少小鼠心肌梗死面积和血清肌钙蛋白-I水平。
*   Per2−/−小鼠中，强光对心肌的保护作用消失。
*   强光增加心脏中腺苷和cAMP水平，该效应在Per2−/−小鼠中消失。
*   强光增加心脏HIF1A-HRE结合，特别是在ZT15时。
*   内皮特异性PER2缺陷小鼠中，强光的心脏保护作用消失。
*   强光治疗显著增加健康志愿者血浆 PER2 蛋白水平和磷酸果糖激酶活性，降低甘油三酯水平。

### d) 独立性与交互作用
*   PER2缺陷消除强光诱导的腺苷和cAMP升高。
*   ADORA2B缺陷消除强光对血管屏障功能的改善作用。
*   HIF1A结合于ANGPTL-4和CLDN1启动子区域，该效应依赖于PER2。

### e) 差异化事实
*   强光诱导的心肌保护在ZT15时相比ZT3时略弱。
*   运动诱导的心肌保护需要2周，而强光诱导仅需1周。
*   在Per2−/−小鼠中，运动诱导的心肌保护作用消失。
*   强光对内皮屏障的保护在Adora2b−/−小鼠中消失。

### f) 待解释任务点
*   强光暴露如何通过视觉感知系统影响心脏PER2表达。
*   PER2如何调控HIF1A依赖性糖酵解、TCA循环和氧化磷酸化。
*   强光如何通过腺苷-cAMP信号通路调控外周PER2表达。
*   内皮PER2如何调控血管屏障功能，特别是在缺血再灌注损伤中。

## 3. 核心统计结果（新事实）
*   **心肌梗死面积（图1A–C）**： 强光暴露7天 vs 标准光，p < 0.05（ANOVA）。
*   **PER2蛋白水平（图1G）**： 强光暴露7天 vs 标准光，p < 0.05。
*   **腺苷水平（图2I）**： 强光暴露7天 vs 标准光，p < 0.05；Per2−/−小鼠中不显著。
*   **HIF1A-HRE结合（图2N）**： ZT15 vs ZT3，p < 0.05。
*   **血管通透性（图3G–I）**： 强光暴露减少Evans blue渗漏，p < 0.05；内皮特异性PER2缺陷小鼠中不显著。
*   **健康志愿者血浆PER2蛋白（图7B–C）**： 强光暴露增加，p < 0.05。
*   **睡眠效率（图7M）**： 强光暴露提高，p < 0.05。

## 4. 变量定义池
*   PER2（Period 2）
*   HIF1A（Hypoxia-Inducible Factor 1 Alpha）
*   ANGPTL-4（Angiopoietin-Like 4）
*   ADORA2B（Adenosine A2B Receptor）
*   cAMP（Cyclic Adenosine Monophosphate）
*   心肌梗死面积
*   血清肌钙蛋白-I
*   血管通透性（Evans blue渗漏）
*   睡眠效率
*   糖酵解通量（U-13C-葡萄糖代谢）
*   TCA循环酶活性（IDH、ACO、SUCLG）
*   线粒体膜电位（MitoTracker、JC-1）
*   睡眠行为（WASO、睡眠效率、日间活动）
